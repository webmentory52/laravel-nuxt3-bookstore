## Nuxt 3 & Laravel Bookstore App
This repository is for a tutorial for simple application built using Laravel and Nuxt.js 3 for a bookstore app. You can view the tutorial in this [url](https://topicfordevs.com/backend-development/building-a-book-selling-website-with-laravel-and-nuxt-js-3/) 

### Technologies
- Laravel 13
- Nuxt.js 3
- Tailwindcss
